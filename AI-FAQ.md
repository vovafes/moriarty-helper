# 🤖 AI-FAQ: Moriarty-Helper

Это технический документ для ИИ-ассистента, помогающего в поддержке бота Moriarty-Helper.

## 📌 Общий обзор
Данный бот является упрощенной версией системы управления семьей в Discord, сфокусированной на базовых функциях: сборы, тикеты, экономика, АФК/Инактив и мониторинг ВЗП.

## 📂 Структура проекта
- `main.py`: Весь код бота (команды, события, UI).
- `laws_module.py`: Модуль юридического ассистента (работа с базой правил сервера).
- `update_laws.py`: Скрипт для обновления базы правил.
- `laws_raw/`: Папка с markdown-файлами правил сервера.
- `data.json`, `obshak.json`, `points.json`, `chips.json`, `roulette.json`: JSON-хранилища.

## ⚙️ Основные системы
1. **Сборы:** Создание списков на мероприятия с кнопками записи и тредами.
2. **Тикеты:** Базовая система подачи заявок и их рассмотрения.
3. **Экономика:** Система баллов (алмазы 💎) и фишек (🎰), включая простой магазин.
3. **АФК/Инактив:** Отслеживание отсутствующих участников.
4. **ВЗП Мониторинг:** Интеграция с API `vzp-gta5rp.com` для отслеживания войн семей и уведомления участников.
5. **Юридический помощник:** Поиск по базе законов и правил сервера Murrieta.

## 🛠 Технические особенности
- **Библиотека:** discord.py.
- **Синхронизация:** Данные сохраняются в JSON через `save_data()`.
- **Специфика:** В отличие от `multitasking`, здесь нет полноценной интерактивной панели настроек (конфигурация через отдельные команды).

## ⚠️ Важные правила
- **Консистентность данных:** При изменении любого состояния БД (например, `points_db` или `warns_db`) обязательно вызывать `save_data()`.
- **Брендинг:** Футер всех эмбедов — `MORIARTY`.
