# moriarty-helper — Памятка (Updated)

---

## 🚀 Быстрый старт
1. Запустите бота.
2. Выполните команду `!роль_админ @роль` — это назначит главного управляющего.
3. После этого все настройки доступны обладателям этой роли через соответствующие команды.

---

## 📋 Основной функционал

### Сборы (Events)
- Команды: `/vzp`, `/list` (и их префикс-версии `!vzp`, `!vzh`, `!list`).
- Особенности: Авто-теги ролей, создание треда со списком, поддержка резерва и времени.
- Управление: `!замена <id_кого> <id_на_кого>` (в треде), кнопки "Закрыть/Открыть список".
- В треде сбора можно занять/освободить слот, написав его номер (альтернатива кнопкам).
- `!vzh <ЧЧ:ММ> [количество] [название]` — сбор ВЗХ; за 30 минут до времени всем занявшим слот придёт напоминание в ЛС. Дата сбора вычисляется по хардкод-расписанию (Банды — Пн+Ср+Пт+Вс, Мафии — Вт+Чт+Сб+Вс), а не просто "сегодня/завтра" — можно создать `!vzh` заранее, за несколько дней. Фракция переключается в `/панель_настройки` → 🎯 Сборы → !vzh.

### Тикет-система (Заявки)
- Подача через кнопку $\rightarrow$ Форма $\rightarrow$ Создание канала.
- Обработка: Одобрение/Отклонение с уведомлением в ЛС.
- Управление: Кнопки "Открыть тикет" и "Удалить канал" после одобрения.

### Экономика и Магазин
- Валюта: Алмазы 💎 (активность) и Фишки 🎰 (рулетка).
- Магазин: Автоматическая выдача ролей или снятие варнов за баллы.
- Команды: `!баланс`, `!обмен`, `!дать`, `!снять`.

### Приватные комнаты
- Создание канала по триггеру $\rightarrow$ Личная панель управления (слоты, доступ, переименование, передача прав).

### Кабинет рекрута
- Панель создаётся командой `/кабинет_рекрута` (текст/фото настраиваются через `/кабинет_рекрута_текст`, `/кабинет_рекрута_фото` или панель настроек).
- Кнопка **Статистика**: эфемерно показывает рекруту количество одобренных/отклонённых им заявок (счётчик растёт автоматически при обработке тикетов).
- Кнопка **Выдать варн** (только для тикет-менеджера/админов): модальное окно — ID пользователя, причина, номер варна (1-3). Варн ставит нужную варн-роль (`!роль_варн`) и публикует сообщение в канал, заданный командой `/канал_варнов`.
- Варны 1/3 и 2/3 можно снять за баллы через товар `remove_warn` в магазине — снимается по одному уровню за раз (роль меняется на соответствующую), лог-сообщение о варне удаляется. Варн 3/3 за баллы не снимается — только вручную администрацией (`!unwarn`).

### Дополнительно
- **АФК и Инактив:** Панели для отслеживания отсутствующих.
- **Общак:** Система пополнения баланса организации с логами.
- **Личный кабинет:** Эфемеральный профиль с балансом, варнами и статистикой.
- **Feedback:** Система сбора предложений с тредами для обсуждения.
- **Контракты:** Система взятия заданий с отслеживанием времени и участников.
- **ВЗП Мониторинг:** Отслеживание войн семей через API `vzp-gta5rp.com` с уведомлениями.
- **Ассистент (упоминание бота):** отвечает по законам Murrieta, игровой вики gta5rp и актуальным мероприятиям сервера (раздел форума «Мероприятия на сервере» читается вживую). ИИ: Ollama `gpt-oss:120b` (`OLLAMA_API_KEY` в `.env`), при сбое — Groq (`GROQ_API_KEY`). Базы обновляются вручную: `python update_laws.py` (законы) и `python update_wiki.py` (вики).

## 🖥 Веб-панель (ветка `dashboard`)

Панель работает внутри процесса бота на том же `$PORT` (раньше там стоял health-сервер; `/health` по-прежнему отвечает `OK`).

**Настройка один раз** — проще всего скриптом: `venv/bin/python setup_dashboard.py` (спросит значения, допишет `.env` и подскажет адрес для Redirects). Вручную:
1. https://discord.com/developers/applications → ваше приложение → **OAuth2** → Redirects: добавить `<DASHBOARD_URL>/auth/callback`.
2. В `.env` (или переменных хостинга):
   ```
   DISCORD_CLIENT_ID=...
   DISCORD_CLIENT_SECRET=...
   DASHBOARD_URL=https://ваш-домен        # для локального теста: http://localhost:10000
   DASHBOARD_OWNER_IDS=ваш_discord_id     # видит и управляет всеми серверами бота
   ```
3. Открыть `DASHBOARD_URL`, войти через Discord. Доступ только у **Администраторов** сервера (и у владельца); права проверяются заново при каждом запросе. Чтобы пускать и «Управление сервером», добавьте `DASHBOARD_ALLOW_MANAGE_GUILD=1` — но учтите, что такой человек сможет выдать себе админ-роль через панель.

**Структура:** `core/` — SQLite, реестр модулей, журнал действий; `dashboard/` — сервер и интерфейс; `modules/` — модули-cog'и (каждый описывает схему настроек, форма в панели строится сама). Старые JSON-данные и логика `main.py` не тронуты.

**Структура проекта:**
- `main.py` — точка входа (~70 строк): подключает всё остальное.
- `legacy/` — прежний функционал бота, разнесённый из старого `main.py` по файлам (`state.py` — хранилище, `helpers.py`, далее по одному файлу на раздел). Логика не менялась.
- `panel_modules/` — модули панели для старого функционала (заявки, сборы, варны, магазин, кабинеты и т.д.): читают и пишут те же JSON-данные.
- `modules/` — новые модули (cog'и со схемой настроек; данные в SQLite `moriarty.sqlite`).
- `core/` — SQLite, реестр модулей, журнал действий; `dashboard/` — веб-сервер и интерфейс.

**Новые модули (в панели по категориям):**
- Модерация: Логи, Модерация (`/mute /kick /ban /tempban /unban /purge /cases`), AutoMod, Anti-Nuke, Верификация (по умолчанию выкл.), Авто-роли, Роли по кнопкам, Ловушка, Возраст аккаунта, Анти-призрачные пинги, Возврат ролей, Временные роли, Префиксы по ролям, АФК-комната.
- Сообщество: Розыгрыши, Приветствия, Уровни (`/rank /leaderboard`), Идеи (`/suggest`), Опросы (`/poll`), Напоминания (`/remind`), Дни рождения (`/birthday`), Starboard, Закреплённые сообщения, Статистика в каналах.
- Поддержка: Тикеты поддержки (категории, закрепление, оценка, архив переписок в панели).
- Команда: Проверка активности (ежедневный отчёт), Оценки команды (`/rate`).
- Инструменты: Автоматизации (правила «если → то»).
- Старый функционал в панели: «Семья» (заявки, сборы, варны, кабинеты, общак, контракты, предложения, приватные комнаты, состав, АФК, мониторинг ВЗП, PvP), «Экономика» (баллы и фишки, голос, магазин, казино), «Система» (брендинг, админ-роли, бэкапы, войс-присутствие).

**Тесты:** `sh tests/run_all.sh` (или `venv/bin/python -m tests.test_<имя>`). Демо панели без Discord: `venv/bin/python -m dashboard.devserver` → http://localhost:8080/dev-login.

## 🧩 Модули, перенесённые из панели AlphaCloud

Все они настраиваются в веб-панели; команды собраны в группу `/tools` (у Discord лимит 100 глобальных слэш-команд, у бота свободно мало — группа занимает один слот).

- **Сервер:** Auto Slowmode, Временные голосовые, ЛС по ролям, Автопубликация, Автопинг, Автоответчик, Конструктор команд (`/tools cmd`).
- **Сообщество:** Список изменений (`/tools changelog`), Рассылка (кнопка подписки), Задачи (`/tools todo`), Партнёрства, Система отзывов (`/tools vouch`, `/tools vouches`), Мини-игры (`/tools blackjack|roulette|coinflip|daily|games_top` + канал Counting), Конструктор эмбедов.
- **Поддержка:** Уведомления, Сортировка (`/tools queue`), Часы, Вызов (`/tools call`), Активность голосовой поддержки, Записи (`/tools entry`).
- **Команда:** Список команды, Обновления команды (`/tools team_add|team_kick|team_warn`), Отсутствия (`/tools absence`), Обязательная запись (AP), Фракции.
- **Панель:** страница «Аналитика», сброс модуля к умолчаниям, новый тип поля `rules` (повторяемые записи).

Не переносилось намеренно: Premium/подписки, ИИ-чат, Интеграции.

**Дизайн панели:** Dark Mode (OLED), Fira Sans / Fira Code (шрифты лежат в `dashboard/static/fonts`, внешних запросов нет), зелёный акцент, SVG-иконки (сгенерировано по ui-ux-pro-max).
