## Введение

Анимации — неотъемлемая часть ролевого процесса, придающая персонажу индивидуальность и выразительность. С их помощью можно показывать физическое состояние персонажа, изменять походку и черты лица, жестикулировать в диалогах и сопровождать практически любое действие.

## Меню анимаций

Меню анимаций открывается нажатием клавиши U. Интерфейс меню включает:
• Поиск — строка в верхней части меню для быстрого поиска нужной анимации по названию.
• Избранные — вкладка с анимациями, отмеченными звёздочкой справа от каждой анимации.
• История — вкладка с последними использованными анимациями.
• Сценарии — вкладка с уникальными анимациями, доступными только членам определённых фракций. Список доступных анимаций указан на странице каждой фракции в разделе «Сценарии».

## Горячие клавиши

Нажав ПКМ по любой анимации, её можно назначить в один из 6 горячих слотов. Горячие клавиши для слотов назначаются в F10 → Настройки → Управление — после этого нужную анимацию можно запускать мгновенно, не открывая меню.

## Категории анимаций

• Для диалогов — жесты и мимика для сопровождения разговоров.
• Реакции — анимации эмоциональных откликов на происходящее.
• Сидеть/лежать — позы отдыха и расслабления.
• Спорт — спортивные движения и упражнения.
• Неприличные — анимации неприличного характера.
• Стойка — варианты базовой стойки персонажа.
• Танцы — танцевальные движения различных стилей.
• Ситуативные — анимации для конкретных игровых ситуаций.
• С оружием — позы с оружием в руках.
• Походки — изменения стиля ходьбы персонажа.
• Эмоции — анимации, изменяющие выражение лица персонажа для передачи различных эмоциональных состояний.
• Стиль стрельбы — варианты анимаций при использовании оружия.
• Сценарии — эксклюзивные анимации для фракций.
Выбранные походка, стиль стрельбы и эмоция сохраняются после выхода из игры.
Танцевальные анимации недоступны при низком уровне настроения персонажа.
Для использования стилей стрельбы необходимо иметь 10-й уровень навыка «Стрельба».
