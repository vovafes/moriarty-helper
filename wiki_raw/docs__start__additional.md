## Введение

Дополнительная информация — это техническая справка по клиенту: какие компоненты нужны, чтобы игра не вылетала, чем записывать игровой процесс и что делать с частыми ошибками RAGE:MP.

## ПО для стабильной работы

Установите эти компоненты до первого запуска — без них игра вылетает чаще всего:
• .NET Framework — версии 4.6 и выше;
• Microsoft Visual C++ Redistributable — все актуальные версии;
• DirectX — последняя версия;
• актуальные драйверы видеокарты.
Драйверы видеокарты качайте только с сайта производителя и обновляйте регулярно: устаревший драйвер — одна из самых частых причин вылетов.

## Программы для видеозаписи

В споре с другим игроком или с администрацией видеозапись — главный аргумент. Записывать можно чем угодно из этого списка:
• NVIDIA App — для видеокарт NVIDIA, пишет через ShadowPlay почти без нагрузки на систему;
• AMD Radeon ReLive — то же самое для видеокарт AMD, средствами драйвера;
• OBS Studio — бесплатно, без ограничения по времени и без водяных знаков;
• Bandicam — в бесплатной версии накладывает водяной знак;
• Fraps — запись и счётчик FPS, в бесплатной версии добавляет логотип.
Держите запись включённой постоянно. Доказать свою правоту без видео почти невозможно, а включить его задним числом уже поздно.

## Ошибки RAGE:MP

Самые частые ошибки клиента и способы их починить. Если у решения несколько шагов, выполняйте их по порядку: если первый не помог, переходите к следующему.

### Your game version is not supported by RAGE Multiplayer
• Зайдите в папку с GTA V и удалите файл GTA5.exe.
• Запустите PlayGTA5.exe и дождитесь запуска игры.
• Выйдите из игры и запустите RAGE:MP заново.
Если ошибка осталась, пробуйте дальше:
• Переустановите Rockstar Games Launcher.
• Проверьте целостность файлов игры.
• Запустите мультиплеер через updater.exe.
• Переустановите игру.

### Clientside packages checksums mismatch! Trying again...
Удалите папку client_packages в директории RAGE:MP и подключитесь снова.

### Error: master list is not responding
Список серверов временно недоступен. Подключитесь через «Прямое подключение».

### Failed to retrieve the install directory
При установке RAGE:MP вы не указали путь к игре. Нажмите «OK» и укажите папку с GTA V.

### FATAL ERROR:.NET Host did not initialize correctly
• Обновите Windows до последней версии.
• Установите актуальную версию.NET Framework.
• Прогоните систему утилитой восстановления системных компонентов.
• Перезагрузите компьютер.

### Please launch RAGE Multiplayer as admin
Закройте Steam и Rockstar Games Launcher, затем запустите RAGE:MP от имени администратора.

### После выбора сервера игра запускается с чёрным экраном и закрывается
Почти всегда это конфликт со сторонними программами:
• Закройте все фоновые программы.
• Отключите оверлеи и сторонние утилиты.
• Подключитесь заново.

### Чёрный экран и бесконечная загрузка
• Перенесите папку RAGE:MP на другой диск.
• Переустановите Rockstar Games Launcher.

### Зависание после нажатия кнопки подключения
Обычно не запускается сама игра. Откройте одиночную GTA V: если она стартует, пробуйте подключиться к серверу снова.

### Краш сразу после подключения к серверу
Отключите стороннее ПО: Sandboxie, виртуальные машины и тому подобное.

### RAGE:MP запускается в трее
Установите последние обновления Windows 10 или 11.

### После запуска ничего не происходит
• Включите VPN.
• Перезапустите подключение к серверу.
• Временно отключите антивирус.

### Запускается одиночная игра вместо мультиплеера
• Запустите RAGE:MP от имени администратора.
• Установите обновления Windows — нужна версия 10 или выше.

### Мышка застряла в центре экрана
• Зайдите в одиночную GTA V.
• Откройте настройки и перейдите в раздел «Мышь / клавиатура».
• Поставьте параметру «Способ ввода для мыши» значение Raw Input.
Если вашей ошибки в списке нет, создайте обращение в технический раздел.
